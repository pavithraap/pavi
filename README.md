# E-commerce Data Analysis

A Python script that cleans and analyzes e-commerce order data, calculates sales metrics, and displays a revenue-by-category chart.

## Requirements

- Python 3.9 or newer
- Your authorized CSV file: `ecommerce_dirty_dataset_375_rows file.csv task 1.csv`

The dataset is not included in this public repository. Keep it private and place your local copy beside `pro-2.py` before running the script.

## Run

```powershell
python -m pip install -r requirements.txt
python "pro-2.py"
```
